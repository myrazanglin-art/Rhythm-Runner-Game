Rhythm Runner

// SYSTEM_OVERVIEW

I engineered a fully automated pipeline that converts arbitrary audio files into playable rhythm game levels. By abandoning manual charting, I built a system that dynamically generates Easy, Normal, and Hard charts for complex genres like experimental electronic, post-rock, and indie music.

我构建了一个全自动的流水线，能够将任意音频转化为可玩的音游关卡。抛弃了人工打谱，我让系统针对实验电子、后摇等复杂流派，实时生成动态难度的谱面。

// COMPUTER_MUSIC_&_DSP

Instead of relying on basic BPM tracking, I extract 15+ complementary descriptors to deeply analyze the audio structure.

我并没有依赖单调的 BPM 追踪，而是提取了 15 种以上的多维描述符来深度剖析音频结构：

> Extracting: spectral_centroid, spectral_rolloff, spectral_flatness, ZCR...
> Running HPSS (Harmonic-Percussive Source Separation)...
> Segmenting via CQT Chroma and Recurrence Matrix...
  • Spectral Flux & Dynamics: I mapped RMS energy to dynamically scale obstacle density, ensuring quiet sections don't get flooded with notes, while drops go crazy.
  • HPSS & Melodic Contours: Using HPSS and piptrack, I isolated harmonic melodic gestures to generate sustained hold notes that follow the music's phrasing.
  • Lane Allocation: Notes are assigned to dual lanes based on frequency-band dominance (high-band to upper lane, low-band to lower).

// ENGINE_ARCHITECTURE

  • Stage 1: Python Offline Analysis
    I used librosa and numpy to serialize multi-dimensional features into a JSON beatmap, completely bypassing human error.
  • Stage 2: Godot Real-time Execution
    I implemented a distance-based judgment system in GDScript, spawning entities perfectly in sync with the audio timeline.
