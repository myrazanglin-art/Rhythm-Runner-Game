Rhythm Runner

Automatic Beatmap Generation Through Multi-Layer Audio Analysis.

A Muse Dash-inspired 2D rhythm game where obstacles and enemies are automatically generated from arbitrary audio files using deep audio signal processing.

🚀 Core Architecture

This project features a fully automated two-stage pipeline:

  • Stage 1: Python & Librosa: Extracts 15+ descriptors including FFT/STFT, onset strength, RMS energy, and HPSS to generate JSON beatmaps.
  • Stage 2: Godot Engine: Ingests JSON charts and runs a dual-lane side-scrolling gameplay with precise distance-based judgment.
