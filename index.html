Rhythm Runner

// Music-Driven Side-Scrolling Game

🌸 项目简介 / Project Overview

Rhythm Runner 是一款受《Muse Dash》启发的 2D 音乐节奏游戏。但与传统音游不同，我们构建了一个全自动的谱面生成流水线（Pipeline）。

Rhythm Runner is a Muse Dash-inspired 2D rhythm game. Unlike traditional rhythm games, we built a fully automated beatmap generation pipeline.

系统能够将任意音频文件转化为可玩的关卡，通过深度音频分析与程序化合成，自动生成 Easy、Normal、Hard 三种动态难度的谱面。

The system converts arbitrary audio files into playable levels, automatically generating dynamic charts for Easy, Normal, and Hard modes through deep audio analysis and procedural synthesis.

🎛️ 实验音乐与音频分析 / Audio DSP & MIR

我们没有依赖单调的 BPM 节拍，而是针对实验电子、后摇、独立音乐等复杂音频，提取了超过 15 种深度特征。

We didn't rely on monotonous BPM beats. Instead, we extracted 15+ deep features tailored for complex audio like experimental electronic, post-rock, and indie music.
  • 时域与频谱 / Temporal & Spectral: 起音检测 (Onsets)、频谱质心 (Centroid)、频谱通量 (Flux)。
  • 能量与动态 / Energy & Dynamics: RMS 包络、动态范围、高频与低频段能量。
  • 谐波与旋律 / HPSS & Melody: 使用 HPSS 分离打击乐与谐波，用 Piptrack 提取旋律轮廓 (Contours)。

⚙️ 核心架构 / Core Architecture

  • Stage 1: Python & Librosa
    负责离线音频分析，提取 15+ 维度特征，并基于段落强度动态生成 JSON 格式的谱面文件。
  • Stage 2: Godot Engine
    接收 JSON 谱面，基于距离的实时判定系统（Distance-based judgment），运行双轨横版跑酷玩法。
